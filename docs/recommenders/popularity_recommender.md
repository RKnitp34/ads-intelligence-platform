# Popularity Recommender

## Goal

Recommend the most popular videos to users.

## Business Use Cases

- New users
- Cold start
- Anonymous users
- Homepage fallback
- System fallback

## Advantages

- Fast
- No training
- Easy to explain
- Strong baseline

## Limitations

- No personalization
- Popularity bias
- Long-tail ignored
- Same recommendations for everyone

## Inputs

Master Dataset

## Output

Top N Videos
